Prime Force 🚀

Prime Force is a team-based educational web project developed as part of the Fullstack Developer course at GoIT.
The project was created to gain practical experience in building a modern responsive web application, working in a team, using Git and GitHub, and applying frontend development best practices.

Cross-browser compatibility

👥 Teamwork

The project was developed collaboratively using Git and GitHub.
We worked with feature branches, commits, pull requests, and code integration.
